# Release notes: v1.1.1-beta4
Release date: 2026-09-15

## English

### Structured editors for shared core settings

The Additional collections section on the Basics page now uses forms instead of a raw JSON editor.

Certificate providers support all three provider types available in the bundled core:

- ACME, including account keys, EAB, HTTP-01, TLS-ALPN-01, DNS-01 through AliDNS, Cloudflare or ACME-DNS, key type, profile and HTTP client selection;
- Tailscale certificates from an existing Tailscale endpoint;
- Cloudflare Origin CA with API token or Origin CA key, RSA or ECC certificates and selectable validity.

HTTP client forms cover the Go and Apple engines, HTTP versions 1 through 3, version fallback, headers, HTTP/2 receive windows, concurrent streams, HTTP/3 packet and path MTU settings, TLS and the shared dial options. Switching to HTTP/1 removes options that HTTP/1 cannot use.

Network namespace forms cover both core modes. `default` opens an existing Linux namespace by path. `unshare` creates an isolated namespace when the core starts and can write its process ID to a file. Saving the form only changes the configuration; it does not create a namespace immediately.

The forms reject missing or duplicate tags and invalid numbers, durations, email addresses, URLs and HTTP headers. Closing a form without saving leaves the stored configuration untouched. Editing one field preserves unknown future fields, explicit `false` and `0` values, lists and secrets.

### QUIC settings open correctly

The QUIC settings switch now opens an empty settings block for Hysteria, Hysteria 2 and TUIC. Opening it does not write defaults. Turning it off removes only the QUIC options and leaves the rest of the protocol configuration in place.

### Upgrade

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.1-beta4/install.sh \
  | sudo bash -s -- v1.1.1-beta4
```

Verify:

```sh
/usr/local/s-ui/sui -v   # 1.1.1-beta4
systemctl is-active s-ui  # active
```

This update does not change the database schema. Download a database backup before upgrading a production server.

## Русский

### Формы для общих настроек ядра

В разделе «Основы», в блоке «Дополнительные коллекции», вместо редактора JSON теперь обычные формы.

Форма провайдеров сертификатов поддерживает все три типа из комплектного ядра:

- ACME с ключом учётной записи, EAB, проверками HTTP-01, TLS-ALPN-01 и DNS-01 через AliDNS, Cloudflare или ACME-DNS, выбором типа ключа, профиля и HTTP-клиента;
- сертификаты Tailscale от существующего эндпоинта Tailscale;
- Cloudflare Origin CA с токеном API или ключом Origin CA, сертификатами RSA или ECC и выбором срока действия.

В форме HTTP-клиента есть движки Go и Apple, версии HTTP с первой по третью, переход на запасную версию, заголовки, окна приёма HTTP/2, ограничение одновременных потоков, параметры пакетов и MTU для HTTP/3, TLS и общие настройки исходящего соединения. При переходе на HTTP/1 форма удаляет параметры, которые эта версия не использует.

Форма сетевых пространств имён поддерживает оба режима ядра. `default` открывает существующее пространство Linux по пути. `unshare` создаёт изолированное пространство при запуске ядра и может записать идентификатор процесса в файл. Сохранение формы меняет конфигурацию, но не создаёт пространство сразу.

Формы отклоняют пустые и повторяющиеся теги, неверные числа, интервалы времени, адреса почты, URL и заголовки HTTP. Закрытие без сохранения не меняет конфигурацию. Правка одного поля сохраняет неизвестные поля будущих версий, явные значения `false` и `0`, списки и секреты.

### Настройки QUIC открываются из пустой конфигурации

Переключатель параметров QUIC теперь открывает пустой блок у Hysteria, Hysteria 2 и TUIC. При открытии форма не записывает значения по умолчанию. Выключение удаляет только параметры QUIC и не затрагивает остальные настройки протокола.
