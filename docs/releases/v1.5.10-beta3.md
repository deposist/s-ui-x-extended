# Release Notes: v1.5.10-beta3
Release date: 2026-06-23

This beta fixes the Regional Presets drawer where components (such as switches, radio buttons, expand panels, and text fields) failed to render and the "Preview Changes" button was locked. It also refactors the UI of the drawer using standard Vuetify components and classes for better borders, headers, and visual separation.

## Bug Fixes

- Fixed a bug where Vuetify components inside the Regional Presets drawer failed to resolve because of dynamically resolved components in JS render functions (bypassing the `vite-plugin-vuetify` compiler). Toggling switches and radio buttons is now working.
- Fixed a bug where the "Preview Changes" button was permanently locked (disabled) because the switches were not functional and the "disable presets" state was not considered a previewable state.
- Fixed layout and spacing issues in the Regional Presets drawer. Added proper dividers, borders, and typography so text boundaries and sections are clearly separated.

# Примечания к релизу: v1.5.10-beta3
Дата релиза: 2026-06-23

Эта бета исправляет ошибку в панели региональных пресетов, из-за которой компоненты (переключатели, радиокнопки, аккордеоны исключений и текстовые поля) не рендерились, а кнопка «Preview Changes» оставалась неактивной. Также улучшен внешний вид панели за счет использования стандартных компонентов и классов Vuetify для лучшего отображения границ, заголовков и разделения контента.

## Исправления ошибок

- Исправлена ошибка, из-за которой компоненты Vuetify внутри панели пресетов не могли разрешиться (из-за использования динамического рендеринга через JS, который игнорировал компилятор `vite-plugin-vuetify`). Теперь переключатели и радиокнопки работают исправно.
- Исправлена ошибка, из-за которой кнопка «Preview Changes» оставалась заблокированной (неактивной) из-за неработающих переключателей и из-за того, что отключение пресетов не распознавалось как доступное для предпросмотра изменение.
- Улучшена разметка, границы и разделители в панели региональных пресетов. Добавлены стандартные карточки, отступы и разделители, благодаря чему текст и подразделы визуально четко отделены друг от друга.
