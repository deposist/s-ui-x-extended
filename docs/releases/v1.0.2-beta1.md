# S-UI-X Extended v1.0.2-beta1

Version 1.0.2-beta1 adds managed personal AmneziaWG 2.0 devices, simplifies the regional routing and DNS presets, and fixes several administration and installation issues.

## Changes

- Users can create named AmneziaWG devices in Telegram, download the exact `.conf` file or a QR code, rotate keys, and revoke devices.
- Device private keys and preshared keys are encrypted in the database. Preshared keys are removed from endpoint API responses and passed to the core only in memory.
- Global and per-tariff limits control how many devices a user can create. The panel reports traffic, handshake state, client counters, and synchronization status.
- Managed endpoint peers are read-only in the endpoint editor. The reconciler repairs missing peers and incomplete add, rotate, or revoke operations after a crash.
- Database backup and restore include the paid-subscription tables used by tariffs, payments, and managed devices.
- RU and ZH routing and DNS presets now use one direct outbound. Applying a preset removes old managed rules but keeps custom routing and DNS rules.
- Edit Bulk can add an inbound to all clients when `Clients: All` is selected.
- `s-ui` reads the saved language file directly instead of waiting for terminal input.
- The installer downloads release assets with curl using HTTPS-only redirects, retries, timeouts, and mandatory SHA-256 verification.

## Upgrade

Upgrade normally. Database migrations run automatically.

Managed AmneziaWG devices require `SUI_SECRETBOX_KEY` and an AWG 2.0 WireGuard endpoint. Set the public endpoint address, device subnet, and DNS values under Paid Subscriptions before users create devices.

To run the menu temporarily in English:

```sh
sudo env SUI_LANG=en s-ui
```

# S-UI-X Extended v1.0.2-beta1

Версия 1.0.2-beta1 добавляет управляемые персональные устройства AmneziaWG 2.0, упрощает региональные пресеты маршрутизации и DNS, а также исправляет несколько проблем в администрировании и установке.

## Изменения

- Пользователь может создать именованное устройство AmneziaWG через Telegram, скачать точный файл `.conf` или QR-код, сменить ключи и отозвать устройство.
- Приватные ключи устройств и preshared keys зашифрованы в базе. Preshared keys удалены из ответов endpoint API и передаются в core только в памяти.
- Число устройств ограничивается глобально или тарифом. В панели отображаются трафик, handshake, счётчики клиента и состояние синхронизации.
- Пиры управляемого endpoint доступны в редакторе только для чтения. Reconciler восстанавливает отсутствующие пиры и незавершённые операции добавления, ротации или отзыва после сбоя.
- Backup и restore базы данных включают таблицы платных подписок, тарифов, платежей и управляемых устройств.
- RU и ZH пресеты маршрутизации и DNS теперь используют один direct outbound. При применении удаляются старые управляемые правила, но сохраняются пользовательские правила маршрутизации и DNS.
- В Edit Bulk можно массово добавить inbound всем клиентам, выбрав `Clients: All`.
- `s-ui` читает сохранённый язык напрямую из файла и больше не ждёт ввод из терминала.
- Установщик загружает release assets через curl с HTTPS-only redirects, повторами, тайм-аутами и обязательной проверкой SHA-256.

## Обновление

Обновляйтесь обычным способом. Миграции базы выполняются автоматически.

Для управляемых устройств AmneziaWG требуется `SUI_SECRETBOX_KEY` и WireGuard endpoint с профилем AWG 2.0. До выдачи устройств настройте публичный адрес endpoint, подсеть устройств и DNS в Paid Subscriptions.

Временный запуск меню на английском:

```sh
sudo env SUI_LANG=en s-ui
```
