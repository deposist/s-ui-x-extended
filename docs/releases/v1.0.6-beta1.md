# S-UI-X Extended v1.0.6-beta1

Adds sudoku and mieru share links, makes the sudoku http-mask mode visible in the inbound editor, and ships a console menu for the AmneziaWG device key-encryption key.

## Sudoku and mieru share links

Sudoku and mieru deliver their client config as JSON, so `LinkGenerator` produced no URI link and the raw-links tab stayed empty. Both upstream clients define a link format, so the panel now emits them.

- `sudoku://`: base64url of the single-letter JSON payload, matching `SUDOKU-ASCII/sudoku` (`internal/config.shortLinkPayload`). Sudoku is keyless, so the shared inbound key and the transport fields are read from the inbound. Legacy http-mask mode and pure-downlink are omitted the same way the upstream encoder omits them. Sudodroid and the Go CLI `-link` import this form.
- `mierus://`: the `enfein/mieru` simple URL (`mierus://user:pass@host?profile&port&protocol`). Picked over the standard `mieru://` form because it needs no protobuf schema. Mieru is not keyless: the per-user name and password come from the client config; host, ports and transport come from the inbound. A `listen_ports` range `a:b` becomes `a-b`, one port/protocol pair per range.

`clientDelivery` stays `json` for both, so the JSON subscription path and the issue #4 assignability fix are untouched. The link is an addition, not a replacement.

## Sudoku http-mask mode

Issue #4 reported sudoku only working in legacy mode. The inbound http-mask section had no heading and an empty mode selector with no hint, so the mode field was easy to miss and an empty value silently meant the core default (legacy).

- The inbound http-mask fields now sit in a titled card, matching the outbound editor.
- The mode selector has a placeholder and a hint that an empty value means the core default and that the client only follows the mode if its core supports it.
- The recommended preset sets `http_mask_mode=legacy` so the field is populated and visible.

The out_json builder already carried every mode into the client config; a regression test now locks legacy/stream/poll/auto/ws.

## Raw-links tab wording

The raw-links tab said "No raw client links are stored" for JSON-delivered protocols, which read like a failure. It now explains that some protocols have no URI link and are delivered through the JSON subscription, and points to the Sing-box tab for import or QR.

## AmneziaWG console key

- Menu item 23 in `s-ui` is "Generate env keys" with a submenu for the session cookie key (`SUI_COOKIE_KEY`) and the AmneziaWG device key (`AWG_KEY_ENC`). The AWG option generates the key when it is missing from `/etc/s-ui/secretbox.env`, wires up the systemd drop-in, and offers a restart. An existing key is kept unless a rotation is confirmed.
- Fixed `write_env_value` in the console script appending a duplicate line instead of replacing the value when an env key already existed.
- Added `scripts/setup-awg-key.sh` for the same check-and-generate as a standalone command.

## Notes

- Existing sudoku and mieru clients get their links on the next save of the client or the inbound, the same way the issue #4 assignability fix rolled out.
- The link formats were verified against the current upstream clients (`SUDOKU-ASCII/sudoku` v0.4.8, `enfein/mieru` v3.33.0). A large version gap on the client core could still diverge.
