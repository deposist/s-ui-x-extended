# S-UI-X Extended v1.0.9

Version 1.0.9 contains the work released in the 1.0.9 beta series after version 1.0.8. It moves the core to sing-box-extended 2.6.5 with AmneziaWG 3.0, adds the Call protocol and new protocol options, and fixes database restore, WARP endpoint creation, the beta-to-stable update path, and periodic AWG reconcile.

## AmneziaWG 3.0 and the new core

- The bundled core is `sing-box-extended 2.6.5`. Managed AWG endpoints and device configs use the AmneziaWG 3.0 option set: header protection key, content padding addition, rekey/reject/keepalive timings, and max handshake attempts. J1/J2/J3 and itime are gone.
- Existing AWG 2.0 endpoint options migrate to 3.0 automatically on the first start after the upgrade. WARP endpoints get the removed 2.x fields (`s1`-`s4`, `h1`-`h4`, `header_protection_key`) cleaned and timing defaults added.
- Amnezia 2.x clients remain compatible with the new core.
- TrustTunnel no longer writes the `bbr_profile` field, which sing-box 2.6.x removed. Re-save a trusttunnel inbound or outbound saved before this release.

## New protocols and options

- New Call protocol: a server-side WebRTC bridge (dion, telemost, vk, wbstream) as inbound or outbound. The inbound creates a call room and clients join through a `join_link`. The `with_call` build tag is enabled in all release builds.
- New protocol options: VPN client/server (default gateway, pool size, reconnect and reject delays), AnyTLS `client_metadata`, MASQUE license and private keys, and multiplex `rmux`.

## Fixes

- Periodic endpoint AWG reconcile no longer fails with a bare `AWG reconcile failed` log. Endpoint-scoped devices now reconcile against the managed endpoint's own tag, and reconcile errors log the endpoint ID with the sanitized cause.
- Database restore no longer deadlocks behind an open realtime WebSocket. The socket releases its maintenance lease right after the handshake, and cron jobs skip ticks silently during a restore instead of spamming `cron: skip`.
- WARP Endpoint creation accepts the peer endpoint Cloudflare returns. The `host` field may be a domain, and the `v4`/`v6` fields may carry a placeholder port of `0`; the panel substitutes a usable port from the `ports` list or the well-known `2408`.
- A stable release selected while tracking the beta channel validates against the release's `main` manifest. This fixes `update manifest is invalid` when a beta installation graduates to stable without changing its saved channel. Prerelease artifacts still require a beta manifest.
- Cronet release builds install a pinned Debian archive keyring package verified by SHA-256 instead of downloading keys from a public keyserver.

## Build and security

- Built with Go 1.26.6, which fixes seven Go standard library vulnerabilities published on 2026-08-13 (net/url, html/template, crypto/tls, net/http, encoding/xml, encoding/asn1, and x/net/idna).

## Upgrade

The installer preserves the panel database and configuration. Existing AWG 2.0 endpoint options migrate automatically on first start; no manual configuration change is required.

Run on Linux:

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.0.9/install.sh \
  | sudo bash -s -- v1.0.9
```

If you are already logged in as `root`:

```sh
bash <(curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.0.9/install.sh) \
  v1.0.9
```

Check the installed version and service state:

```sh
/usr/local/s-ui/sui -v
systemctl is-active s-ui
journalctl -u s-ui -n 50 --no-pager
```

The first command must report `1.0.9`, and `systemctl` must print `active`.

Beta users can update to stable 1.0.9 directly from the panel: the beta1 fix validates the stable archive against its `main` manifest, so no channel switch is required.

# S-UI-X Extended v1.0.9

Версия 1.0.9 включает изменения всей линейки beta после 1.0.8. Ядро переведено на sing-box-extended 2.6.5 с AmneziaWG 3.0, добавлены протокол Call и новые опции протоколов, исправлены восстановление базы, создание WARP Endpoint, переход с beta на stable и периодический AWG reconcile.

## AmneziaWG 3.0 и новое ядро

- В комплект входит `sing-box-extended 2.6.5`. Управляемые эндпоинты AWG и конфиги устройств используют набор опций AmneziaWG 3.0: ключ защиты заголовков, дополнение контента, тайминги rekey, reject и keepalive, максимум попыток рукопожатия. Поля J1/J2/J3 и itime убраны.
- Существующие опции эндпоинтов AWG 2.0 мигрируют на 3.0 автоматически при первом запуске после обновления. У WARP-эндпоинтов вычищаются удалённые поля 2.x (`s1`-`s4`, `h1`-`h4`, `header_protection_key`) и добавляются тайминги по умолчанию.
- Клиенты Amnezia 2.x продолжают работать с новым ядром.
- TrustTunnel больше не пишет поле `bbr_profile`: sing-box 2.6.x его убрал. Входящий или исходящий trusttunnel, сохранённый до этого релиза, пересохраните.

## Новые протоколы и опции

- Новый протокол Call: серверный WebRTC-мост (dion, telemost, vk, wbstream) как входящий или исходящий. Входящий создаёт комнату, клиенты подключаются по ссылке `join_link`. Сборочный тег `with_call` включён во всех сборках.
- Новые опции протоколов: VPN client/server (шлюз по умолчанию, размер пула, задержки reconnect и reject), `client_metadata` у AnyTLS, ключи license и private у MASQUE, мультиплексирование `rmux`.

## Исправления

- Периодический AWG reconcile для эндпоинтов больше не падает с голым `AWG reconcile failed` в логе. Устройства, привязанные к эндпоинту, сверяются с собственным тегом, а ошибки reconcile пишут ID эндпоинта и причину.
- Восстановление базы больше не зависает из-за открытого веб-сокета. Сокет освобождает блокировку обслуживания сразу после рукопожатия, а задания cron молча пропускают такт вместо спама `cron: skip`.
- Создание WARP Endpoint принимает peer-endpoint в том виде, в котором его отдаёт Cloudflare. Поле `host` может содержать домен, а порт в `v4`/`v6` может быть заглушкой `0`; панель подставляет рабочий порт из списка `ports` или стандартный `2408`.
- Стабильный релиз, выбранный через beta-канал, проверяется по манифесту `main`. Это устраняет `update manifest is invalid` при переходе с beta на stable без смены канала. Для предварительных версий по-прежнему требуется манифест beta.
- Сборка Cronet устанавливает закреплённый пакет ключей Debian с проверкой SHA-256 и не запрашивает ключи с публичного сервера.

## Сборка и безопасность

- Сборка выполнена на Go 1.26.6, который закрывает семь уязвимостей стандартной библиотеки, опубликованных 2026-08-13 (net/url, html/template, crypto/tls, net/http, encoding/xml, encoding/asn1 и x/net/idna).

## Обновление

Установщик сохраняет базу и настройки панели. Существующие опции эндпоинтов AWG 2.0 мигрируют автоматически при первом запуске. Ручное изменение конфигурации не требуется.

Команда для Linux:

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.0.9/install.sh \
  | sudo bash -s -- v1.0.9
```

Если вы уже вошли как `root`:

```sh
bash <(curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.0.9/install.sh) \
  v1.0.9
```

Проверьте версию и службу:

```sh
/usr/local/s-ui/sui -v
systemctl is-active s-ui
journalctl -u s-ui -n 50 --no-pager
```

Первая команда должна показать `1.0.9`, команда `systemctl` - `active`.

Пользователи beta могут обновиться до стабильной 1.0.9 напрямую из панели: исправление beta1 проверяет стабильный архив по манифесту `main`, поэтому переключение канала не требуется.
