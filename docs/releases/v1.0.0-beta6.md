# s-ui-x-extended v1.0.0-beta6

Rebases the panel onto s-ui-x v1.5.10-beta3 while keeping the sing-box-extended
core. Every upstream feature is now available on the extended core, alongside
the existing extended-protocol set.

## What's new

- Full functional parity with s-ui-x v1.5.10-beta3 (UI, protocols, routing,
  DNS, subscriptions, management features).
- All sing-box-extended protocols preserved (Mieru, Sudoku, TrustTunnel, SSH,
  MTProxy, MASQUE, OpenVPN, Bond, Failover, Fallback, limiters, VPN endpoints,
  providers, profiler, VLESS encryption, mKCP/XHTTP, unified_delay).
- Provider manager integrated into the upstream codebase.
- Branding updated to "S-UI-X Extended".
- Version logic handles the fork's own versioning line alongside upstream
  schema versions.

## Upgrade

No manual migration needed. The binary runs the normal migration chain on
startup.
