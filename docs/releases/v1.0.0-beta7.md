# s-ui-x-extended v1.0.0-beta7

This beta keeps the v1.0.0-beta6 rebase on s-ui-x v1.5.10-beta3 and fixes the follow-up panel issues found during runtime checks.

## What's new

- Fixed the `Invalid login` and `CSRF token was not returned` loop after an expired or lost session. The panel now clears local auth state and returns to the login page without making a CSRF-protected logout request first.
- CSRF token loading now reports backend errors directly, so an invalid session is shown as `Invalid login` instead of a missing-token error.
- Repeated invalid-session responses from polling are handled once until the next successful login.
- The panel self-update checker now uses `https://github.com/deposist/s-ui-x-extended` for release lookup and downloads.
- Extended protocol editors are restored in both Classic and Nexus. The extended inbound, outbound, endpoint, DNS, service, and client options are visible in the panel.

## Upgrade

No manual migration is needed. The binary runs the normal migration chain on startup and updates `settings.version` to `1.0.0-beta7`.
