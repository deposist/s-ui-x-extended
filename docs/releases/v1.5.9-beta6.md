# Release Notes: v1.5.9-beta6
Release date: 2026-06-18

Small follow-up to v1.5.9-beta5.

**EN**

## 1. WireGuard endpoint editor now opens reliably

When adding a WireGuard endpoint, the editor could open with only the type and tag. Key, address, port, and peer fields were missing until the editor was closed and opened again. The editor now loads those fields on the first open.

No database, API, or configuration changes are required.

**RU**

Небольшое дополнение к v1.5.9-beta5.

## 1. Редактор WireGuard-эндпойнта теперь открывается стабильно

При добавлении WireGuard-эндпойнта редактор иногда открывался только с типом и тегом. Поля ключей, адреса, порта и пиров появлялись только после закрытия и повторного открытия. Теперь редактор загружает эти поля сразу.

Изменения базы данных, API или конфигурации не требуются.
