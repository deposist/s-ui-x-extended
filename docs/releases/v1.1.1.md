# S-UI-X Extended v1.1.1

Version 1.1.1 consolidates the improvements and fixes from the 1.1.1 beta series after version 1.1.0. The bundled core moves to sing-box-extended 1.14, AmneziaWG adds 3.1 obfuscation options with reliable hot reload, the failover scheduler cleans up removed group state, and the installer finishes cleanly in non-interactive pipes.

## Core upgrade and protocols

- Bundled core updated to sing-box-extended `v1.14.0-extended-2.7.5`.
- OpenVPN client and server endpoints can be configured directly from the panel.
- Added support for the `cloudflared` inbound and USB/IP client and server services.
- Updated protocol configuration fields for Hysteria, Hysteria 2, TUIC, Mieru, MASQUE, and WireGuard.
- On first start after the upgrade, saved configurations migrate to the 1.14 schema in a single transaction.

## AmneziaWG 3.1 and WireGuard

- Added AmneziaWG 3.1 switches to the WireGuard endpoint form:
  - Random trailers appends pseudo-random bytes to packets to obscure fixed handshake sizes. The setting must match on both server and client.
  - Disable cookies turns off cookie replies and MAC2 checks under load.
- Repinned the engine to `deposist/wireguard-go v0.0.5-extended-1.6.2` to resolve packet buffer length mismatches during handshakes with trailers enabled.
- Saving an active managed AWG endpoint (such as toggling 3.1 options) re-injects client preshared keys (PSKs) during hot reload instead of requiring a full service restart.

## Failover memory management

- Fixed memory retention in `FailoverJob` (PR #10): state entries and member health maps are now dropped from memory whenever failover groups or individual members are removed from configuration.

## Installer and system services

- Fixed fresh installs through pipes (`curl ... | sudo bash -s`): the final interactive settings prompt now runs only when standard input is a terminal. Under pipe input, the installer uses the default answer and finishes cleanly without triggering an accidental rollback.
- Fixed a core shutdown hang with MTProxy enabled: sing-box now closes the listening socket before waiting for active connections to drain.

## Settings and validation

- Structured forms for certificate providers (ACME, Tailscale, Cloudflare Origin CA), reusable HTTP clients, and Linux network namespaces now appear on the Basics tab in Settings.
- Hardened inbound validation: saving TrustTunnel without TLS is blocked, Mieru and TrustTunnel generate client passwords when empty, and generated core configs are validated before commit.
- Updated dependencies for upstream security patches: `google.golang.org/grpc` to v1.83.2, `golang.org/x/crypto` to v0.56.0, `golang.org/x/mod` to v0.40.0, and `github.com/pion/stun/v3` to v3.1.5.

## Upgrade

The installer preserves the panel database and configuration. The database schema is unchanged.

Run on Linux:

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.1/install.sh \
  | sudo bash -s -- v1.1.1
```

If you are logged in as `root`:

```sh
bash <(curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.1/install.sh) \
  v1.1.1
```

Check the installed version and service state:

```sh
/usr/local/s-ui/sui -v
systemctl is-active s-ui
journalctl -u s-ui -n 50 --no-pager
```

The first command must report `1.1.1`, and `systemctl` must print `active`.

# S-UI-X Extended v1.1.1 (Русский)

Версия 1.1.1 объединяет наработки и исправления всей линейки beta после 1.1.0: переход на ядро sing-box-extended 1.14, поддержку AmneziaWG 3.1, очистку памяти планировщика failover, исправление отката установщика и структурированные формы настроек.

## Ядро и протоколы

- Комплектное ядро обновлено до sing-box-extended `v1.14.0-extended-2.7.5`.
- В панели доступны эндпоинты клиента и сервера OpenVPN.
- Добавлена поддержка inbound `cloudflared` и служб USB/IP (клиент и сервер).
- Добавлены новые поля протоколов для Hysteria, Hysteria 2, TUIC, Mieru, MASQUE и WireGuard.
- При первом запуске сохранённая конфигурация переносится на схему 1.14 в рамках одной транзакции.

## AmneziaWG 3.1 и WireGuard

- В форме WireGuard-эндпоинта появились переключатели AmneziaWG 3.1:
  - «Случайные трейлеры» добавляют случайные байты к пакетам, скрывая фиксированный размер рукопожатий. Параметр должен быть одинаковым на сервере и клиенте.
  - «Отключить cookies» отключает cookie-ответы и проверки MAC2 при высокой нагрузке.
- Движок обновлён до `deposist/wireguard-go v0.0.5-extended-1.6.2`, устраняя ошибку размера буфера при кодировании рукопожатий с включёнными трейлерами.
- Горячая перезагрузка управляемого AWG-эндпоинта (например, при переключении опций 3.1) теперь корректно подставляет preshared keys (PSK) клиентов без необходимости перезапускать всю службу.

## Очистка памяти в failover

- Устранено накопление неактуального состояния в `FailoverJob` (PR #10): внутреннее состояние групп и карты здоровья участников удаляются из оперативной памяти при их исключении из конфигурации.

## Установщик и системные службы

- Исправлена установка через канал (`curl ... | sudo bash -s`): запрос настроек теперь задаётся только при интерактивном терминале. При передаче через пайп установщик выбирает ответ по умолчанию и штатно завершает установку без ложного отката.
- Исправлено зависание остановки ядра при активном MTProxy: слушающий порт закрывается до ожидания завершения клиентских сессий.

## Настройки и валидация

- На вкладке Basics в настройках появились формы для провайдеров сертификатов (ACME, Tailscale, Cloudflare Origin CA), общих HTTP-клиентов и пространств имён Linux.
- Усилена проверка при сохранении inbound: блокировка сохранения TrustTunnel без TLS, автоматическая генерация паролей Mieru и TrustTunnel, проверка итоговой конфигурации ядра до фиксации в базе данных.
- Обновлены зависимости с патчами безопасности: `google.golang.org/grpc` (v1.83.2), `golang.org/x/crypto` (v0.56.0), `golang.org/x/mod` (v0.40.0) и `github.com/pion/stun/v3` (v3.1.5).

```sh
  | sudo bash -s -- v1.1.1
```

Если вы вошли под `root`:

```sh
bash <(curl -fLsS \
```
