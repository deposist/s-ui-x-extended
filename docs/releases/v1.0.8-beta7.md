# S-UI-X Extended v1.0.8-beta7

Version 1.0.8-beta7 fixes the Russia regional routing and DNS preset. This is a beta. Test it on a non-critical server before using it in production.

## Fixed

- The Russia preset now downloads `geosite-category-ru.srs` from the maintained runetfreedom `russia-v2ray-rules-dat` collection.
- The previous SagerNet URL pointed to `geosite-geolocation-ru.srs`, which was removed upstream and returned HTTP 404. Because rule-set materialization is intentionally fail-closed, that response prevented the preset from changing the configuration.
- The replacement is an HTTPS binary sing-box rule-set. The panel still downloads and validates it before writing a local rule-set path into the configuration.
- The preset source label and its URL regression test now match the replacement source.

## Verification

- The replacement URL responds with HTTP 200 and `application/octet-stream` content.
- `go test ./...` passes: 26 packages passed and 3 had no tests. `go vet ./...` also passes.
- Frontend ESLint, TypeScript checking, and the production Vite build pass.
- The local Windows Vitest runner fails before registering any tests with a shared Vitest runtime error across all 53 test files. The tagged Linux release workflow runs the suite again under Node.js 25 and will not publish artifacts unless it passes.

## Upgrade notes

- No database migration is required.
- Re-apply the Russia regional preset after upgrading. The panel will download the replacement file and update the local rule-set manifest.
