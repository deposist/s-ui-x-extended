# S-UI-X Extended v1.0.6-hotfix1

This hotfix corrects the Sudoku section in the client editor. Version 1.0.6 generated per-inbound split keys on the backend, but the UI still showed the beta3 instruction for manual CLI generation and did not display the generated values.

## Fixed

- Removed the outdated instruction to run `sudoku -keygen -more` and paste a Split Private Key into the panel.
- The Sudoku row now lists one read-only Split Private Key for each assigned Sudoku inbound.
- Each key is labeled with the inbound name, hidden by default, and can be revealed with the eye button for manual copying.
- Clients without generated Sudoku keys see an accurate note explaining that the backend creates them automatically after assignment and save.
- The `mtproxy` Secret field is unchanged. It is a separate editable credential and is not related to Sudoku key generation.

## Upgrade notes

- No database migration is required.
- Existing generated Sudoku keys are not changed or regenerated.
- Links, QR codes, and subscriptions are unchanged; this hotfix only repairs the client-editor display and wording.
