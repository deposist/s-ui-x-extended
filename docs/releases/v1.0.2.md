# S-UI-X-Extended v1.0.2

Version 1.0.2 adds managed personal AmneziaWG 2.0 devices and fixes the `s-ui` menu startup when a language is already saved.

## Changes

- Users can create named AmneziaWG devices in Telegram, download the exact `.conf`, scan a QR code, rotate keys, and delete devices.
- Device keys are encrypted at rest. Preshared keys are not exposed through endpoint APIs or stored in endpoint options.
- Device limits can be set globally or per tariff. Traffic, handshake state, and reconciliation status are shown in the panel.
- Managed endpoint peers are read-only in the endpoint editor and are repaired automatically after crashes or drift.
- The installer uses curl retries, timeouts, HTTPS-only redirects, and SHA-256 verification for release assets.
- `s-ui` now reads the saved language file directly instead of waiting for terminal input.

## Upgrade

Upgrade normally. Database migrations run automatically. To use managed AmneziaWG devices, configure `SUI_SECRETBOX_KEY`, an AWG 2.0 WireGuard endpoint, the public endpoint address, subnet, and DNS in Paid Subscriptions.

To run the menu temporarily in English:

```sh
sudo env SUI_LANG=en s-ui
```

# S-UI-X-Extended v1.0.2

Версия 1.0.2 добавляет управляемые персональные устройства AmneziaWG 2.0 и исправляет запуск меню `s-ui`, когда язык уже сохранён.

## Изменения

- Пользователь может создать именованное устройство в Telegram, скачать точный `.conf`, получить QR-код, сменить ключи и удалить устройство.
- Ключи устройств зашифрованы в базе. Preshared keys не попадают в endpoint API и не хранятся в options endpoint.
- Лимит устройств задаётся глобально или в тарифе. В панели видны трафик, handshake и состояние синхронизации.
- Пиры управляемого endpoint доступны только для чтения и восстанавливаются автоматически после сбоев или рассинхронизации.
- Установщик загружает release assets через curl с повторами, тайм-аутами, HTTPS-only redirects и проверкой SHA-256.
- `s-ui` читает сохранённый язык из файла и больше не ждёт ввод из терминала перед показом меню.

## Обновление

Обновляйтесь обычным способом. Миграции базы выполняются автоматически. Для управляемых устройств AmneziaWG настройте `SUI_SECRETBOX_KEY`, WireGuard endpoint с профилем AWG 2.0, публичный адрес, подсеть и DNS в Paid Subscriptions.

Временный запуск меню на английском:

```sh
sudo env SUI_LANG=en s-ui
```
