# S-UI-X Extended v1.0.2

Stable v1.0.2 promotes the v1.0.2-beta1 line and reworks how managed AmneziaWG 2.0 servers are configured. A server is now a regular endpoint that the admin assigns to clients, the same way inbounds are assigned. The old global settings under Paid Subscriptions keep working.

## Changes since v1.0.2-beta1

- A WireGuard endpoint can be marked as a managed AmneziaWG 2.0 server directly in the endpoint form. The form takes a public address, DNS servers, and a default device limit. The AWG 2.0 obfuscation profile is filled in automatically.
- Managed servers are assigned to clients in the client form, next to the inbound list. Removing the assignment revokes the client's devices on that server. An endpoint with active assignments cannot be deleted.
- Devices belong to a client and server pair. Several managed servers can run at the same time, each with its own peers, IP allocation, reconciliation, and traffic counters.
- The client form has a new devices tab. The admin can create a device for a client, show its QR code, download the `.conf` file, rotate keys, and revoke the device. Every action is written to the audit log, and config downloads are served with `Cache-Control: no-store`.
- The Telegram bot lists the servers assigned to the client and creates devices on the server the user picks. Devices created under the old global configuration keep working through the same bot menus.
- Reconciliation and statistics run for every managed server on a fixed schedule, in addition to the existing loop for the legacy global endpoint.

## Included from v1.0.2-beta1

- Managed personal AmneziaWG 2.0 devices with Telegram configuration and QR delivery, encrypted keys, device limits, traffic statistics, key rotation, revocation, and crash recovery.
- Simplified RU and ZH routing and DNS presets that use one direct outbound and preserve custom rules.
- Edit Bulk can add an inbound to all clients.
- `s-ui` reads the saved language file directly instead of waiting for terminal input.
- Release downloads use HTTPS-only redirects, retries, timeouts, and mandatory SHA-256 verification.

## Upgrade

Upgrade normally. Database migrations run automatically. The new `client_endpoint_access` table and the `endpoint_id` device column are created on first start.

Existing installations that use the global AWG settings under Paid Subscriptions do not need to change anything. To switch to the new model, mark the endpoint as a managed server in the endpoint form and assign it to clients.

Device key encryption still requires the `AWG_KEY_ENC` environment variable.

# S-UI-X Extended v1.0.2

Стабильная v1.0.2 повышает линейку v1.0.2-beta1 до stable и меняет настройку управляемых серверов AmneziaWG 2.0. Сервер теперь является обычным endpoint, который админ назначает клиентам так же, как inbound'ы. Старые глобальные настройки в Paid Subscriptions продолжают работать.

## Изменения после v1.0.2-beta1

- WireGuard endpoint можно пометить как управляемый сервер AmneziaWG 2.0 прямо в форме endpoint. В форме задаются публичный адрес, DNS-серверы и лимит устройств по умолчанию. Профиль обфускации AWG 2.0 заполняется автоматически.
- Управляемые серверы назначаются клиентам в форме клиента рядом со списком inbound'ов. Снятие назначения отзывает устройства клиента на этом сервере. Endpoint с активными назначениями нельзя удалить.
- Устройство принадлежит паре клиент и сервер. Несколько управляемых серверов работают одновременно, у каждого свои peers, распределение IP, reconcile и счётчики трафика.
- В форме клиента появилась вкладка устройств. Админ может создать устройство для клиента, показать QR-код, скачать файл `.conf`, сменить ключи и отозвать устройство. Каждое действие записывается в аудит, а скачивание конфигурации отдаётся с `Cache-Control: no-store`.
- Telegram-бот показывает назначенные клиенту серверы и создаёт устройства на выбранном сервере. Устройства, созданные при старой глобальной настройке, продолжают работать через те же меню бота.
- Reconcile и статистика выполняются для каждого управляемого сервера по расписанию, в дополнение к существующему циклу для старого глобального endpoint.

## Включено из v1.0.2-beta1

- Управляемые персональные устройства AmneziaWG 2.0 с выдачей конфигураций и QR через Telegram, шифрованием ключей, лимитами устройств, статистикой трафика, ротацией ключей, отзывом и восстановлением после сбоя.
- Упрощённые RU и ZH пресеты маршрутизации и DNS с одним direct outbound и сохранением пользовательских правил.
- Edit Bulk может массово добавить inbound всем клиентам.
- `s-ui` читает сохранённый язык напрямую из файла и не ждёт ввод из терминала.
- Загрузка релиза использует HTTPS-only redirects, повторы, тайм-ауты и обязательную проверку SHA-256.

## Обновление

Обновляйтесь обычным способом. Миграции базы выполняются автоматически. Таблица `client_endpoint_access` и колонка `endpoint_id` у устройств создаются при первом запуске.

Существующим установкам с глобальными настройками AWG в Paid Subscriptions ничего менять не нужно. Для перехода на новую модель пометьте endpoint как управляемый сервер в форме endpoint и назначьте его клиентам.

Для шифрования ключей устройств по-прежнему требуется переменная окружения `AWG_KEY_ENC`.
