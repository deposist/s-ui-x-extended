# S-UI-X Extended v1.0.8-beta10

Version 1.0.8-beta10 repairs the release pipeline after beta9 exposed failures in CI script execution, published-tag handling, and multi-platform Docker smoke tests. It does not change the panel database or runtime configuration.

## CI and release validation

- CI runs `tests/release-tag-validation.sh` through Bash. The repository stores shell scripts without the executable bit, so direct execution could fail with `Permission denied` before the checks started.
- The shared checkout action stages the tag validators and `check-release-state.sh` in runner temporary storage before it checks out the requested tag. A checked-out tag cannot replace this copy of the guard.
- Release preflight accepts a tag with no matching GitHub release and can resume one draft release. It rejects an already-published release, duplicate matches, or a malformed `draft` field before expensive build jobs begin.
- A published tag remains immutable for release purposes. If rebuilt files differ from the published SHA-256 values, publication stops and the build must move to a new SemVer tag.

## Docker publishing

- The final multi-platform smoke check reads the OCI index and resolves the exact manifest digest for `linux/amd64` and `linux/arm64`.
- Each container starts from its immutable platform digest, which Docker can load independently. The workflow also checks each selected digest against the digest produced by that architecture's build job before promoting final tags.

## Regression coverage

- Release validation tests cover explicit Bash invocation, tag and checkout validation, trusted guard staging, release states, and fail-closed asset verification.
- The workflow assertions verify that Docker smoke tests use the resolved platform digest rather than the shared index digest.

## Upgrade notes

- The default Compose image and frontend package version are `1.0.8-beta10`.
- No database migration is required.
- No manual configuration change is required.
- This is a beta. Test it on a non-critical server before using it in production.
