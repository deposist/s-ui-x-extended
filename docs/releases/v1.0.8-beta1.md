# S-UI-X Extended v1.0.8-beta1

Version 1.0.8-beta1 is a security prerelease. It updates vulnerable dependencies, hardens the self-updater and release pipeline, and fixes recovery around IP certificate issuance.

## Security

- Updated Go to 1.26.5 and `quic-go` to 0.59.1 to include published Go and QUIC security fixes.
- Updated Axios to 1.18.1 and the affected `brace-expansion` packages to patched versions.
- The self-updater rejects oversized artifacts, checksum responses, and archive members. It also removes partial files after failed downloads or extraction.
- Telegram API responses now have a fixed size limit.
- Security checks are blocking and use pinned tools. Release jobs verify checksums, scan artifacts, publish an SPDX SBOM, and attach build provenance.

## Fixed

- IP certificate issuance no longer stops after the panel service is shut down. The command result is reported, the script attempts to restore the prior service state, and the management menu remains available after success or failure.
- Malformed Clash proxy-group templates return an error instead of causing an index panic.

## Upgrade notes

- No database migration is required.
- This is a beta release. Test IP certificate issuance on a non-critical public server before using it in production.
