# Release Notes: v1.5.8-beta3 (2026-06-14)


Beta release adding **TLS certificates for bare IP addresses** and streamlining the interface. **No database migration or configuration changes required.**

## What changed

### 1. TLS certificates for bare IP addresses (issue + auto-renew)

A new **IP certificate** card in **Settings → Maintenance** allows issuing Let's Encrypt TLS certificates for IP addresses without domain names (RFC 8738 / `shortlived` profile).

**Details:**
* **In-process ACME exchange** via `go-acme/lego` - works identically on Linux, Windows, and Docker (no need for `acme.sh`).
* **HTTP-01 standalone** challenge on a configurable port (default: 80).
* Certificate application options:
  * to the **panel's HTTPS listener** (`webCertFile`/`webKeyFile`) - requires panel restart;
  * to an **inbound TLS profile** - uses hot-reload (only affected inbounds reload, **no core restart**, recommended).
* **Auto-renewal:** background job checks every 12 hours; re-issues when < 72 hours of validity remain (~160 hours ≈ 6.7 days).
* Automatic re-issue when the **target IP changes** - ensures the live certificate never holds a stale address.
* Certificate and key stored under `<db>/certs` (key file permissions: `0600`).
* ACME account key **encrypted at rest** - not returned by the settings API or shown in the UI.
* **Safety measures:** target IP validated against private, loopback, link-local, CGNAT, cloud-metadata, and reserved ranges (no DNS lookups) - both on manual issue and auto-renew; issuing is a privileged, audited action.

### 2. Config Doctor moves to Settings → Maintenance


* Now located in **Settings → Maintenance**, alongside Backup and the new IP-certificate card.
* Shared between Nexus and classic layouts (previously appeared in two separate places).
* Behaviour unchanged: remains a **read-only dry-check** that assembles the full sing-box config and constructs a sing-box instance without starting or restarting the running core.

### 3. Streamlined Nexus Home overview

* Removed standalone **System Status** panel and **Config Doctor** card.
* IPv4/IPv6 addresses now appear inside the **live-traffic KPI tile**.
* **Recent events** shows 10 entries (was 6).
* Result: a cleaner Home page focused on KPIs, top clients, and recent events.


### 4. Hardening and fixes

* **IP-change re-issue:** auto-renew now re-issues when the configured target IP differs from the certificate on disk (prevents serving old IP certificates until expiry).
* **Stricter issue-time validation:** direct issue requests now validate ACME email and challenge port using the same rules as the settings page:
  * email validation uses Go standard library mail parser (rejects `@`-only inputs, embedded control characters, and display-name forms).
* **Missing icon fixed:** `shield-check` glyph (used by the IP-certificate card) now registered in the Lucide icon map.

## Verification

**Backend:**
* `go build ./...` - passed.
* `go vet ./service ./api ./cronjob` - passed.
* `go test ./service ./api ./cronjob` - passed (new unit tests cover renew decision, IP/email/port validation, ACME orchestration, certificate store, PEM parsing, settings round-trip, and TLS server-block patch).

**Frontend:**
* `vue-tsc --noEmit` - passed.
* `eslint` - passed.
* `vitest` - passed (25 files, 129 tests, including locale parity and Lucide icon-map scan).

## Notes and requirements

* **No database migration** required.
* Applying a certificate to the panel **restarts the panel**; applying to an inbound TLS profile is **hot** (avoids restart).
* Issuance uses **Let's Encrypt production**; use `SUI_ACME_DIR_URL` environment variable to point at staging/Pebble for testing.
* Binding challenge port 80 on Linux requires privileges - use a custom port or reverse proxy if the panel does not run as root.

# Примечания к релизу: v1.5.8-beta3 (2026-06-14)

Бета-релиз с добавлением **TLS-сертификатов для голых IP-адресов** и оптимизацией интерфейса. **Миграция базы и изменения конфигурации не требуются.**

## Что изменилось

### 1. TLS-сертификаты для голых IP-адресов (выпуск + автоперевыпуск)

Новая карточка **IP certificate** в **Settings → Maintenance** позволяет выпускать TLS-сертификаты Let's Encrypt для IP-адресов без доменных имён (RFC 8738 / профиль `shortlived`).

**Основные характеристики:**
* **In-process обмен ACME** через `go-acme/lego` - одинаково работает на Linux, Windows и в Docker (не требуется `acme.sh`).
* **ACME-challenge HTTP-01 standalone** на настраиваемом порту (по умолчанию: 80).
* Варианты применения сертификата:
  * к **HTTPS-листенеру панели** (`webCertFile`/`webKeyFile`) - требует перезапуска панели;
  * к **inbound TLS-профилю** - через горячую перезагрузку (перезагружаются только затронутые Inbounds, **без перезапуска ядра**, рекомендуется).
* **Автоперевыпуск:** фоновая задача проверяет каждые 12 часов; перевыпускает, когда остаётся < 72 часов срока действия (~160 часов ≈ 6,7 дней).
* Автоматический перевыпуск при **смене целевого IP** - живой сертификат никогда не хранит устаревший адрес.
* Сертификат и ключ хранятся в `<db>/certs` (права доступа к файлу ключа: `0600`).
* Ключ ACME-аккаунта **шифруется на диске** - не возвращается API настроек и не показывается в UI.
* **Меры безопасности:** целевой IP проверяется на принадлежность к private-, loopback-, link-local-, CGNAT-, cloud-metadata- и зарезервированным диапазонам (без DNS-резолва) - как при ручном выпуске, так и при автоперевыпуске; выпуск - привилегированное действие с аудитом.

### 2. Config Doctor переезжает в Settings → Maintenance

* Теперь находится в **Settings → Maintenance**, рядом с Backup и новой карточкой IP-сертификата.
* Общий для Nexus- и классической раскладки (ранее был в двух местах).
* Поведение не изменилось: остаётся **read-only dry-check**, который собирает полный конфиг sing-box и создаёт инстанс sing-box без запуска или перезапуска работающего ядра.

### 3. Оптимизированный обзор главной Nexus
* Убрана отдельная панель **System Status** и карточка **Config Doctor**.
* Адреса IPv4/IPv6 теперь отображаются внутри **KPI-плитки живого трафика**.
* **Recent events** показывает 10 записей (было 6).
* Результат: более чистый интерфейс главной страницы с фокусом на KPI, топ-клиентах и недавних событиях.

### 4. Усиление надёжности и исправления
* **Перевыпуск при смене IP:** автоперепуск теперь перевыпускает сертификат, если настроенный целевой IP отличается от указанного в сертификате на диске.
* **Строже валидация при выпуске:** прямые запросы на выпуск теперь проверяют email ACME и порт challenge по тем же правилам, что и страница настроек.
* **Исправлена отсутствующая иконка:** глиф `shield-check` теперь зарегистрирован в карте иконок Lucide.
