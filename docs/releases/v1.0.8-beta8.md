# S-UI-X Extended v1.0.8-beta8

Version 1.0.8-beta8 fixes two failures: realtime updates could stop after an offline WebSocket token request, and Vitest could fail before registering tests on Windows. This is a beta. Test it on a non-critical server before using it in production.

## Fixed

- If the browser goes offline while requesting a WebSocket token, the client switches to degraded polling and retries when the network returns. Repeated offline and online transitions now end in the `connected` state.
- Frontend test commands resolve the Windows path before starting Vitest. This keeps one runner context when the shell and filesystem use different letter case for the same drive.
- `npm test -- <file>` still passes the requested test file to Vitest.

## Verification

- The complete frontend unit suite passes: 53 files and 357 tests.
- The focused WebSocket Playwright tests pass: 2 tests.
- Frontend ESLint, TypeScript checking, and the production Vite build pass.
- Go tests pass: 26 packages passed and 3 had no tests. `go vet ./...` also passes.
