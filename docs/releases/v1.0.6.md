# S-UI-X Extended v1.0.6

Adds a console menu entry to generate the AmneziaWG device key-encryption key, and fixes an env-key rewrite bug in the console script.

## Why

Web-panel self-update replaces the binary and restarts the service, but does not run `install.sh`, so it never provisions `AWG_KEY_ENC`. A panel updated only through the web UI could still fail managed AmneziaWG device operations with `awg: AWG encryption key is unavailable`. The console menu now offers a direct way to generate the key.

## Console menu

- Menu item 23 in `s-ui` is now "Generate env keys" and opens a submenu:
  1. Generate session cookie key (`SUI_COOKIE_KEY`)
  2. Generate AmneziaWG device key (`AWG_KEY_ENC`)
- The AWG option checks whether `AWG_KEY_ENC` is present in `/etc/s-ui/secretbox.env`. If it is missing, it generates a 32-byte key, writes it to the environment file, ensures the systemd drop-in loads that file, and offers to restart the service. An existing key is kept unless the operator confirms a rotation, because rotating it after devices exist makes their stored key material undecryptable.

## Fixed

- `write_env_value` in the console script appended a duplicate line instead of replacing the value when an env key already existed. An `exit 0` inside the awk detector block was overwritten by the trailing `END { exit 1 }`, so the "already present" branch never ran. This affected rotating `SUI_COOKIE_KEY` from the menu as well. The detector now records the match in a flag and lets `END` decide the exit code.

## Included script

- `scripts/setup-awg-key.sh` performs the same check-and-generate for `AWG_KEY_ENC` as a standalone command, for operators who prefer not to open the menu.
