# Release Notes: v1.1.1-beta3
Release date: 2026-09-15

The panel runs on a newer sing-box-extended core. Protocols the core already supported are now editable in the panel, and saved configurations upgrade themselves on first start.

**EN**

## 1. OpenVPN is now part of the panel

OpenVPN appears in Endpoints in two forms.

OpenVPN Client connects this server to an external OpenVPN server, corporate or commercial. OpenVPN Server accepts connections from ordinary OpenVPN clients, such as phone apps, routers and corporate hosts, so those devices do not need a sing-box client installed.

Both forms take TLS with your own certificate and key, a username and password, UDP or TCP transport, data ciphers and auth digest, MTU and MSS. In server mode you also point at a CA, so the panel can validate clients.

One limitation is worth knowing before you plan anything. Address `127.0.0.1` is not reachable through the tunnel, so point clients at the real interface address of the service.

## 2. New inbound and new services

`cloudflared` is a new inbound. It exposes the server through a Cloudflare Tunnel with a tunnel token.

Two new services, `usbip-server` and `usbip-client`, share USB devices over the network on Linux and Windows.

## 3. New editors

Certificate providers (ACME) let the core request certificates by itself. HTTP clients are named clients with their own headers, and rule-sets and providers can reference them. Network namespaces run listeners or outbound connections inside a Linux network namespace.

## 4. More options in existing protocols

Hysteria, Hysteria 2 and TUIC gained idle timeout, keep-alive period, stream and connection receive windows, a limit on concurrent streams, initial packet size and path MTU discovery. Hysteria 2 also gained a BBR profile, realm support with STUN servers, a maximum port-hop interval and an option to disable the Chrome parrot. Mieru gained MTU and handshake mode, MASQUE gained a local address and port, and WireGuard gained UDP mapping, UDP filtering and UDP NAT limits. Existing AmneziaWG profiles keep working, and the panel does not rewrite them.

## 5. Saved configuration upgrades itself

On the first start of this version the panel converts the saved configuration to the new core schema in one transaction. DNS rules that filtered answers by address become an `evaluate` rule followed by a `match_response` rule, and their order, resolver and fallback survive. A legacy OpenVPN outbound becomes an OpenVPN endpoint with the same tag and settings. An inline ACME block becomes a certificate provider.

When a conversion is not possible, the panel names the path and the reason and leaves those records as they are.

## 6. Subscriptions explain what they skipped

When a subscription format cannot represent a protocol, the panel now skips that entry with a reason in the log and inside the generated file. Before, it disappeared without a word. The JSON subscription keeps every entry.

## Upgrade

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.1-beta3/install.sh \
  | sudo bash -s -- v1.1.1-beta3
```

Verify:
```sh
/usr/local/s-ui/sui -v   # 1.1.1-beta3
systemctl is-active s-ui  # active
```

Download a database backup from the panel before you upgrade. That backup is what a rollback needs. To roll back, stop the service, restore the database file from the backup, then restore the previous binary. The binary alone will not do it, because the schema migration moves in one direction.

This is a beta. Test the new protocols and the automatic migration on a non-critical server before upgrading production.

**RU**

## 1. OpenVPN теперь в панели

OpenVPN живёт в разделе Endpoints и работает в двух режимах.

OpenVPN Client подключает этот сервер к внешнему OpenVPN-серверу, корпоративному или платному. OpenVPN Server принимает обычных OpenVPN-клиентов: приложения на телефонах, роутеры, корпоративные хосты. Ставить sing-box на эти устройства не нужно.

В обоих режимах есть TLS со своим сертификатом и ключом, логин и пароль, транспорт UDP или TCP, шифры данных и хеш, MTU и MSS. В режиме сервера добавляется CA, по которому панель проверяет клиентов.

Одно ограничение стоит знать заранее. Адрес `127.0.0.1` через туннель недостижим, поэтому клиентам нужен реальный адрес интерфейса.

## 2. Новое входящее подключение и новые службы

`cloudflared` открывает сервер наружу через Cloudflare Tunnel по токену туннеля.

Две новые службы, `usbip-server` и `usbip-client`, передают USB-устройства по сети в Linux и Windows.

## 3. Новые редакторы

Certificate providers (ACME) дают ядру возможность самому запрашивать сертификаты. HTTP clients - это именованные HTTP-клиенты со своими заголовками, на них ссылаются rule-set и провайдеры. Network namespaces запускают слушателей и исходящие соединения внутри сетевого пространства имён Linux.

## 4. Больше настроек у знакомых протоколов

У Hysteria, Hysteria 2 и TUIC появились таймаут простоя, период keep-alive, окна приёма потока и соединения, ограничение на одновременные потоки, начальный размер пакета и поиск MTU пути. У Hysteria 2 добавились BBR-профиль, работа с realm через STUN-серверы, максимальный интервал смены порта и отключение Chrome parrot. У Mieru - MTU и режим рукопожатия, у MASQUE - локальный адрес и порт, у WireGuard - UDP mapping, UDP filtering и лимиты UDP NAT. Существующие профили AmneziaWG продолжают работать, панель их не переписывает.

## 5. Сохранённая конфигурация обновляется сама

При первом запуске этой версии панель приводит сохранённую конфигурацию к схеме нового ядра одной транзакцией. Правила DNS, которые фильтровали ответы по адресам, превращаются в пару `evaluate` и `match_response` с сохранением порядка, резолвера и fallback. Старый OpenVPN-outbound переезжает в эндпоинт OpenVPN с тем же тегом и настройками, а встроенный блок ACME - в certificate provider.

Когда преобразование невозможно, панель называет путь и причину и оставляет эти записи как есть.

## 6. Подписки объясняют, что пропустили

Когда формат подписки не умеет представлять протокол, панель пропускает узел и пишет причину в лог и в сам файл. Раньше он исчезал молча. JSON-подписка сохраняет все узлы.

## Обновление

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.1-beta3/install.sh \
  | sudo bash -s -- v1.1.1-beta3
```

Проверка:
```sh
/usr/local/s-ui/sui -v   # 1.1.1-beta3
systemctl is-active s-ui  # active
```

Перед обновлением выгрузите резервную копию базы данных из панели, именно она понадобится для отката. Возврат делается по шагам. Остановите службу, восстановите файл базы из копии, затем верните прежний бинарный файл. Один бинарник без базы не откатит, миграция схемы идёт только вперёд.

Это бета. Проверьте новые протоколы и автоматическую миграцию на некритичном сервере, прежде чем обновлять рабочий.
