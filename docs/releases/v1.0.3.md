# S-UI-X Extended v1.0.3

v1.0.3 is a bugfix release. It repairs AWG device creation from the panel, the upgrade path from v1.0.2-beta1, the self-update rollback, and sudoku inbound assignment. Everyone on v1.0.2 should upgrade; there are no new features and no configuration changes.

## Fixed

- Creating an AmneziaWG 2.0 device from the client form failed with `awg: invalid request`. The API handler only accepted JSON bodies, while the panel sends form-encoded requests. The handler now picks the decoder based on the request Content-Type, so both the panel and JSON API clients work.
- Upgrading from v1.0.2-beta1 crashed the panel on every start with `no such column: endpoint_id`. Startup rebuilt the `awg_devices` table and lost columns in the process, then tried to index a column that was never added. The table is now left alone once it exists, and indexes are created only after the column migrations have run. Installations that hit the crash recover on their own after this upgrade.
- The self-update rollback never worked on Linux. Restoring the backup wrote into the running binary, which the kernel rejects with `text file busy`. The restore now renames the backup into place, the same way the forward swap installs a new binary.
- A sudoku inbound never appeared in the client edit form's inbound selector, so it could not be assigned to any client (#4). The panel treated "assignable" as "has per-user credentials", and sudoku has none: its clients share a single inbound-level key and receive the outbound through the JSON subscription. Assignability is now derived from the protocol manifest, so a sudoku inbound can be assigned like any other and shows its assigned clients in the inbound list. The sing-box config generation for sudoku is unchanged.

## Also in this release

- Assigning a client to an endpoint that is not a managed AWG server is now rejected instead of silently accepted. Such assignments had no effect: no device manager ever served them.
- Database backups now include the `client_endpoint_access` table, so client-to-server assignments survive a restore.
- An endpoint managed through the legacy global AWG settings is marked as managed in the endpoint list again, and its peers get the same edit protection as endpoints managed through the endpoint form.
- The auto-register inbound selector in paid subscriptions now only offers inbounds that can actually deliver something to a client. Transparent and local types (direct, tun, tproxy and similar) are no longer listed; selecting them had no effect.

## Upgrade

Upgrade normally. No migrations beyond the automatic ones, no new settings.

# S-UI-X Extended v1.0.3

v1.0.3 - исправление ошибок. Починены создание AWG-устройств из панели, путь обновления с v1.0.2-beta1, откат self-update и назначение sudoku-инбаундов. Всем на v1.0.2 стоит обновиться; новых функций и изменений конфигурации нет.

## Исправлено

- Создание устройства AmneziaWG 2.0 из формы клиента завершалось ошибкой `awg: invalid request`. Обработчик API принимал только JSON, а панель отправляет form-encoded запросы. Теперь декодер выбирается по Content-Type запроса, поэтому работают и панель, и JSON-клиенты API.
- Обновление с v1.0.2-beta1 роняло панель при каждом запуске с ошибкой `no such column: endpoint_id`. При старте таблица `awg_devices` пересоздавалась с потерей колонок, после чего создание индекса ссылалось на колонку, которой не было. Существующая таблица больше не трогается, а индексы создаются только после миграций колонок. Установки, попавшие на этот сбой, восстанавливаются сами после обновления.
- Откат self-update не работал на Linux. Восстановление бэкапа писало в работающий бинарник, что ядро отклоняет с ошибкой `text file busy`. Теперь бэкап переименовывается на место, тем же способом, каким устанавливается новый бинарник.
- Sudoku-инбаунд не появлялся в селекторе инбаундов формы клиента, поэтому его нельзя было назначить ни одному клиенту (#4). Панель считала «назначаемым» только инбаунд с per-user учётными данными, а у sudoku их нет: клиенты делят один общий ключ и получают outbound через JSON-подписку. Назначаемость теперь выводится из манифеста протоколов, поэтому sudoku-инбаунд назначается как любой другой и показывает назначенных клиентов в списке инбаундов. Генерация sing-box конфига для sudoku не изменилась.

## Также в релизе

- Назначение клиента на endpoint, который не является управляемым AWG-сервером, теперь отклоняется, а не принимается молча. Такие назначения не имели эффекта: их не обслуживал ни один менеджер устройств.
- Таблица `client_endpoint_access` включена в резервные копии базы, поэтому назначения клиентов на серверы переживают восстановление.
- Endpoint, управляемый через старые глобальные настройки AWG, снова помечается как управляемый в списке endpoint'ов, а его peers защищены от ручного редактирования, как и у endpoint'ов, управляемых через форму.
- Селектор авторегистрации в платных подписках теперь предлагает только инбаунды, которые что-то доставляют клиенту. Прозрачные и локальные типы (direct, tun, tproxy и подобные) больше не показываются; их выбор не имел эффекта.

## Обновление

Обновляйтесь обычным способом. Дополнительных миграций и новых настроек нет.
