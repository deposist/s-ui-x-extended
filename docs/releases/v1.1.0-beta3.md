# S-UI-X Extended v1.1.0-beta3

Version 1.1.0-beta3 fixes three defects that could stop a working setup: managed AWG endpoints with devices could not be edited, a saved call outbound crash-looped the core, and the cooldown log printed a wrong unit. It also adds obfuscation presets and a public endpoint suggestion to the managed AWG form. The database schema is unchanged.

## Fixed

- An endpoint with "Managed AWG server" enabled could not be saved once it had devices. Every edit failed with `managed AWG endpoint peers are controlled by the device manager` although the peers were not touched. The guard compared the peers byte by byte, and the form round-trip reorders JSON keys and reformats whitespace, so the comparison failed on formatting alone. Peers are now compared as a set: normal edits (MTU, DNS, public endpoint) go through, and editing the peers themselves is still rejected.
- Saving a call outbound stored a `server` field that the call schema in the core does not have. Every core start then failed with `json: unknown field "server"`, and sing-box kept restart-looping until the row was deleted from the database by hand. The outbound form no longer shows the address and port fields for call, because call joins a room through `join_link` and has no dial target. The panel also rejects such saves server-side with an error that explains the cause. If you already have a poisoned config, delete the call outbound from the Outbounds page and the core starts again after the restart cooldown.
- The core start cooldown log printed `15ns seconds`. A Go duration division kept the duration type, so the number rendered in nanoseconds. The line now prints the real duration.

## Added

- Two buttons in the Amnezia block of the endpoint form. "Recommended" applies a curated profile: balanced junk padding (Jc 4, Jmin 40, Jmax 90), S values that keep the four packet sizes distinct and stay at or above 12 so header protection can be enabled later without touching S again, the stock init packet prefix, and the fixed timings 120/5/180/10/18. "Hardened (randomized)" generates the whole set on the server with crypto/rand: H1-H4, junk from the balanced distribution, S values from 15-40, and random init packet values I1-I5. Devices must re-download their config or rescan the QR after obfuscation changes; the form shows this warning.
- When "Managed AWG server" is switched on and the public endpoint field is empty, the form suggests the hostname the panel is opened from, plus the listen port. The suggestion follows listen port changes until the field is edited by hand. Stored values are never overwritten, and loopback addresses are never suggested.

## Upgrade

Users of the 1.1.0 beta series, 1.0.9, and the 1.0.9 betas can install this release from the console:

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.0-beta3/install.sh \
  | sudo bash -s -- v1.1.0-beta3
```

If you are already logged in as `root`:

```sh
bash <(curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.0-beta3/install.sh) \
  v1.1.0-beta3
```

After installing, check the version and the service:

```sh
/usr/local/s-ui/sui -v
systemctl is-active s-ui
journalctl -u s-ui -n 50 --no-pager
```

The first command should print `1.1.0-beta3`, and `systemctl` should report `active`. The installer preserves `/usr/local/s-ui/db` and `/etc/s-ui`.

If the core on your server is currently restart-looping with `json: unknown field "server"`, delete the call outbound on the Outbounds page after the upgrade; the core recovers on its own after the cooldown.

This is a beta release. Test it on a non-critical server before using it in production.

# S-UI-X Extended v1.1.0-beta3 (Русский)

Версия 1.1.0-beta3 исправляет три дефекта, способных остановить рабочую установку: управляемые AWG-эндпоинты с устройствами не редактировались, сохранённый call-outbound отправлял ядро в цикл перезапусков, а лог cooldown печатал не ту единицу измерения. Кроме того, в форму управляемого AWG добавлены пресеты обфускации и подсказка публичного адреса. Схема базы данных не меняется.

## Исправления

- Эндпоинт с включённым «Управляемым AWG-сервером» нельзя было сохранить, как только у него появлялись устройства. Любое редактирование завершалось ошибкой `managed AWG endpoint peers are controlled by the device manager`, хотя пиры никто не трогал. Гвард сравнивал пиры побайтово, а раунд-трип через форму переупорядочивает ключи JSON и переформатирует пробелы, так что сравнение падало на одном форматировании. Пиры теперь сравниваются как множество: обычные правки (MTU, DNS, публичный адрес) проходят, а изменение самих пиров по-прежнему отклоняется.
- Сохранение call-outbound записывало поле `server`, которого нет в схеме call в ядре. Каждый старт ядра падал с `json: unknown field "server"`, и sing-box перезапускался по кругу, пока строку не удаляли из базы вручную. Форма outbound'ов больше не показывает поля адреса и порта для call, потому что call подключается к комнате через `join_link` и не имеет адреса для подключения. Панель также отклоняет такие сохранения на сервере с ошибкой, объясняющей причину. Если конфиг уже отравлен, удалите call-outbound на странице Outbounds, и ядро поднимется само после cooldown.
- Лог cooldown старта ядра печатал `15ns seconds`. Деление длительностей в Go сохраняло тип длительности, и число выводилось в наносекундах. Теперь печатается реальная длительность.

## Добавлено

- Две кнопки в блоке Amnezia формы эндпоинта. «Рекомендуемые» применяют выверенный профиль: сбалансированный junk-паддинг (Jc 4, Jmin 40, Jmax 90), значения S, при которых четыре размера пакетов остаются различными и не опускаются ниже 12 (header protection можно включить позже, не трогая S), стандартный префикс init-пакета и фиксированные тайминги 120/5/180/10/18. «Усиленные (рандом)» генерируют весь набор на сервере через crypto/rand: H1-H4, junk из сбалансированного распределения, S из диапазона 15-40 и случайные значения init-пакетов I1-I5. После смены обфускации устройствам нужно перекачать конфиг или пересканировать QR; форма показывает это предупреждение.
- При включении «Управляемого AWG-сервера», если поле публичного адреса пустое, форма подставляет хост, по которому открыта панель, и порт listen_port. Подсказка следует за изменениями listen_port, пока поле не отредактировано вручную. Сохранённые значения не перезаписываются, петлевые адреса не подставляются.

## Обновление

Пользователи бета-серии 1.1.0, 1.0.9 и бет 1.0.9 могут установить релиз из консоли:

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.0-beta3/install.sh \
  | sudo bash -s -- v1.1.0-beta3
```

Если вы уже вошли как `root`:

```sh
bash <(curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.0-beta3/install.sh) \
  v1.1.0-beta3
```

После установки проверьте версию и службу:

```sh
/usr/local/s-ui/sui -v
systemctl is-active s-ui
journalctl -u s-ui -n 50 --no-pager
```

Первая команда должна вывести `1.1.0-beta3`, а `systemctl` должен напечатать `active`. Установщик сохраняет `/usr/local/s-ui/db` и `/etc/s-ui`.

Если ядро на вашем сервере сейчас перезапускается по кругу с ошибкой `json: unknown field "server"`, после обновления удалите call-outbound на странице Outbounds; ядро восстановится само после cooldown.

Это бета-релиз. Проверьте его на некритичном сервере, прежде чем использовать в продакшене.
