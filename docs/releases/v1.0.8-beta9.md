# S-UI-X Extended v1.0.8-beta9

Version 1.0.8-beta9 fixes payment recovery, core lifecycle failures, malformed subscription input, stale frontend requests, and several release and update edge cases. This is a beta. Test it on a non-critical server before using it in production.

## Payments

- Paid orders can complete after their pending deadline if the provider confirms payment. Concurrent confirmation no longer overwrites a paid transition.
- The system stores every provider charge in a durable ledger. Telegram offsets, CryptoBot cursors, and reconciliation cursors advance only after it stores the corresponding work successfully.
- Missing CryptoBot invoices stay recoverable instead of leaving an order pending forever. One failed invoice no longer prevents the remaining cancellation batch from running.
- Refunds restore the capacity bought by the order. They leave current usage and lifetime traffic counters unchanged, report repeated refunds accurately, and surface AWG suspend or resume failures.

## Core, certificates, and networking

- Core startup rolls back partial initialization. Shutdown runs once, stores its result, and no longer races with another close call.
- The core initializes Clash log observers and sends them entries. Panic and fatal log levels still perform their original terminal action after the logger writes the entry.
- WireGuard endpoint removal uses the existing IPC semaphore correctly. The parser rejects allowed IP prefixes with host bits instead of silently masking them.
- Certificate renewal retries a saved pair that failed to apply. The certificate store publishes certificate and private key files together from one complete generation.
- Telegram backup validates the fixed Argon2 profile before key derivation and carries cancellation through snapshot creation, passphrase handling, encryption, and upload.
- Warp rejects incomplete or malformed provider responses and propagates key-generation errors. AWG replay lookup now includes the endpoint ID.

## Subscriptions, API, and web

- Share-link parsers reject missing credentials, malformed hosts and ports, invalid JSON or YAML shapes, and out-of-range ECH data instead of panicking or silently rewriting input.
- Generated links use standard URL and network formatting. Query values are escaped, IPv6 addresses retain brackets, and protocol state no longer leaks from one address to the next.
- Enumeration tracking stays bounded without clearing every counter. Rate-limit settings are read outside the global request lock.
- x-ui import dry-run is read-only. API and CLI handlers return after database errors instead of continuing with invalid values.
- Sessions use the current database handle. Realtime registration and delivery are synchronized. HTTPS redirects preserve the actual TLS port.
- Iframe security headers follow the SameSite setting. Host validation accepts a trailing dot, and immutable caching applies only to hashed assets.

## Frontend

- WebSocket generations prevent an old connection from reconnecting after logout or clearing state from a newer session.
- CSRF refresh uses one in-flight request and retries a failed request once. Data loading and fallback polling no longer overlap or let an older failure invalidate a newer success.
- The router keeps its reload latch, update polling is serialized, and blocked browser storage no longer stops affected views from rendering.
- Saved subscription JSON is checked before use. WireGuard peer editing, TLS tags, row selection, confirm dialogs, and protocol editors now guard missing or stale state.
- TrustTunnel, Sudoku, OpenVPN, ShadowTLS, and Trojan editors keep changes on the actual model and reject destructive key collisions.

## Release and update path

- Release workflows validate tag provenance and artifact metadata before publishing. Cross-platform scripts use the same release-tag contract.
- Panel updates keep a durable rollback snapshot and serialize update application. An interrupted or concurrent update cannot replace the saved rollback state with a partial transaction.

## Upgrade notes

- Normal startup adds the provider-charge ledger used by paid subscriptions.
- No manual configuration change is required.
