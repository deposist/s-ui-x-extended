# v1.0.0-beta3

Third public beta of s-ui-x-extended.

- **Recommended defaults pre-filled across the admin panel** — inbounds,
  outbounds, endpoints, DNS, services, TLS, transports and routing rules now open
  with security-first, ready-to-use values (TUIC/Naive/TrustTunnel `bbr`,
  VLESS/VMess `xudp`, VMess `auto`, OpenVPN `AES-256-GCM`/`SHA256`, Sudoku core
  defaults, TLS `min_version: 1.3`).
- **Dropdowns for fixed-value fields** — congestion controls, Mieru transport/
  multiplexing, Sudoku AEAD/mask modes, SOCKS version, Tun stack, TLS cipher
  suites and more can no longer take an invalid hand-typed token.
- **Editable suggestion comboboxes for free-text fields** — durations, size
  quotas, speeds, listen addresses, time zones, NTP/DNS servers, SSH
  versions/algorithms, health-check URLs, … come with suggestions and a sensible
  default while still accepting custom input.

All tokens were verified against the `sing-box-extended` core; secrets are never
hard-coded and camouflage targets are left empty.

See the [`CHANGELOG.md`](../../CHANGELOG.md) for the summary and
[`SECURITY.md`](../../SECURITY.md) for supply-chain and hardening notes.
