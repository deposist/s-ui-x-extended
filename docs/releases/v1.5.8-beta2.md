# Release Notes: v1.5.8-beta2

Release date: 2026-06-12
**EN**

v1.5.8-beta2 introduces the Personal Ops Pack, a read-only diagnostics and operations layer for s-ui-x admins, especially RU/ZH setups. It adds Config Doctor for checking the generated sing-box configuration without restarting the core, per-client diagnostics to understand why a client may not work, and a named routing/DNS preset gallery with preview-only local changes. The subscription QR dialog has also been redesigned into a clearer Delivery dialog with platform-specific formats, copy/QR actions, visible subscription URLs, and reachability checks.

This release also improves safety and correctness: client connectivity probes are now protected by the same SSRF guard as outbound checks, diagnostics report failed setting reads and time-budget cancellations more accurately, and presets are bound directly to their apply logic to prevent silent no-op entries. No database migration is required, and the new diagnostic tools do not modify your configuration.

**RU**

v1.5.8-beta2 добавляет Personal Ops Pack - read-only слой диагностики и обслуживания для администраторов s-ui-x, особенно для RU/ZH-сценариев. В релизе появился Config Doctor, который проверяет собранный sing-box конфиг без перезапуска ядра, диагностика отдельных клиентов для быстрого понимания, почему клиент может не работать, и галерея готовых пресетов маршрутизации/DNS с локальным preview перед применением. QR-окно подписки переработано в более понятный Delivery-диалог с форматами по платформам, копированием/QR, видимым URL подписки и проверкой доступности.

Также усилены безопасность и корректность: проверки связности клиента теперь защищены тем же SSRF-guard, что и outbound-check, диагностика точнее отличает ошибки чтения настроек и отменённые по таймбюджету проверки, а пресеты напрямую привязаны к своей apply-логике, чтобы не было «пустых» пунктов. Миграция базы не требуется, а новые диагностические инструменты не изменяют конфигурацию.
