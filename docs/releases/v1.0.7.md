# S-UI-X Extended v1.0.7

Version 1.0.7 fixes the Ubuntu management menu, extends the domain-reset action to stop using TLS certificates, and cleans up the Sudoku key controls in the client editor.

## Fixed

- The management menu stays open while systemd reports the service as `activating`, even when `systemctl is-active` returns a non-zero code.
- Status and install checks handle stopped and missing services without terminating the menu.
- Menu item 11 clears `webCertFile`, `webKeyFile`, `subCertFile`, and `subKeyFile` together with the panel domain, listen address, and Web URI. It does not delete certificate files or change IP-certificate settings.
- Automatically managed Sudoku keys no longer have a reset button. Revealed keys are hidden when another client is opened, and the Split Private Key label uses the selected interface language.

## Upgrade notes

- No database migration is required.
- Existing certificate files remain on disk. Menu item 11 only removes their panel and subscription settings.
- Existing Sudoku keys, links, QR codes, and subscriptions are unchanged.
