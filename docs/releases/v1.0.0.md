# v1.0.0

First stable release of s-ui-x-extended. Consolidates beta1–beta3.

- **Extended protocols & transports** — OpenVPN, MASQUE, MTProxy, TrustTunnel,
  WireGuard/AmneziaWG, CCM/OCM, DHCP, QUIC, mKCP/XHTTP, providers, and
  rate/traffic/bandwidth/connection limiters, plus the inherited security and
  reliability hardening.
- **Recommended defaults across the admin panel** — inbounds, outbounds,
  endpoints, DNS, services, TLS, transports and routing rules now open with
  security-first, ready-to-use values (TUIC/Naive/TrustTunnel `bbr`, VLESS/VMess
  `xudp`, VMess `auto`, OpenVPN `AES-256-GCM`/`SHA256`, Sudoku core defaults, TLS
  `min_version: 1.3`).
- **Typed inputs** — dropdowns lock fixed-value fields to valid tokens; editable
  comboboxes suggest sensible defaults for free-text fields while still accepting
  custom input.
- **Full protocol tag set in every build path** — prebuilt Linux tarballs and the
  Windows packages now ship the same protocols as the Docker image / `build.sh`
  (WireGuard/WARP, MASQUE, OpenVPN, MTProxy, Sudoku, TrustTunnel, DHCP-DNS,
  CCM/OCM/OOMKiller). Only Naive (cronet/CGO) still varies by platform.
- **Fix** — the `database` API token scope now grants database export/import and
  x-ui / 3x-ui migration (previously admin-only).
- **Docs** — `docs/scope-matrix.md` corrected to all six token scopes; README
  restructured and fact-checked.

All tokens were verified against the `sing-box-extended` core; secrets are never
hard-coded and camouflage targets are left empty.

See the [`CHANGELOG.md`](../../CHANGELOG.md) for the summary and
[`SECURITY.md`](../../SECURITY.md) for supply-chain and hardening notes.
