# Release Notes: v1.1.1-beta5
Release date: 2026-09-16

The panel's Additional collections section is now visible on the Basics tab. The beta4 release added the structured forms but mounted them on a page the panel no longer uses, so users saw no new fields. This release places them where the Basics tab actually renders.

**EN**

## 1. Where the new forms live now

The Basics tab in Settings shows the Additional collections section. It is the last section on the tab: open Settings, switch to the Basics tab and scroll to the bottom, past Experimental settings. The full order is Logs, NTP settings, Certificate Trust, Clash API, V2Ray API, Experimental settings, then Advanced Collections.

The section holds three editors, each with an add button:

- Certificate providers: ACME, Tailscale and Cloudflare Origin CA;
- reusable HTTP clients;
- Linux network namespaces.

The section appears in both panel layouts, the nexus grid and the classic expansion panels.

## 2. What the three collections do

- Certificate providers. The core obtains certificates on its own instead of you installing them by hand. An ACME provider issues and renews Let's Encrypt certificates through HTTP-01, TLS-ALPN-01 or DNS-01, so an inbound or endpoint with TLS gets a real certificate without manual steps. A Tailscale provider takes certificates from your existing Tailscale endpoint. A Cloudflare Origin CA provider issues certificates for servers behind Cloudflare.
- HTTP clients. A named HTTP transport you configure once: engine, HTTP versions 1 through 3, headers, receive windows, TLS and dial settings. ACME providers, rule-sets and providers reference such a client by tag instead of repeating the settings in each place.
- Network namespaces (Linux only). Default opens an existing namespace by path; unshare creates an isolated namespace when the core starts, and listeners and outbound connections then run inside it. Saving the form only changes the configuration, the panel does not create a namespace by itself.

## 3. What works again

- Adding an item opens the structured form. Fields are validated before saving; an empty required field shows an error instead of silently failing.
- Saved items appear as cards with edit and delete actions. Deleting the last item removes the empty collection from the configuration.
- The panel Save button writes all three collections to the panel database in one request. Verified end to end on a live panel: the stored configuration contains the exact items created in the forms.

## 4. The new protocol fields from beta3, and where to look

Beta3 added core options to existing protocols. They live in the protocol forms on the Inbounds and Outbounds pages, and most appear only after the related toggle is on:

- Hysteria, Hysteria 2 and TUIC: turn on the QUIC settings switch in the protocol form to get idle timeout, keep-alive period, stream and connection receive windows, the concurrent stream limit, initial packet size and path MTU discovery. Hysteria 2 additionally has a BBR profile, realm with STUN servers, the port-hop interval and the Chrome parrot switch.
- Mieru: MTU and handshake mode in the Mieru form.
- MASQUE: local address and port in the MASQUE form.
- WireGuard: UDP mapping, UDP filtering and UDP NAT limits in the WireGuard form.
- OpenVPN client and server endpoints, the cloudflared inbound and the usbip-server and usbip-client services are separate entries on the Endpoints, Inbounds and Services pages.

## Upgrade

```sh
curl -fLsS \
  https://raw.githubusercontent.com/deposist/s-ui-x-extended/v1.1.1-beta5/install.sh \
  | sudo bash -s -- v1.1.1-beta5
```

Verify:

```sh
/usr/local/s-ui/sui -v # 1.1.1-beta5
systemctl is-active s-ui # active
```

The database schema is unchanged from beta4. No migration is required.

## Русский

## 1. Где теперь находятся новые формы

Вкладка «Basics» в настройках показывает раздел «Additional collections». Это последний раздел вкладки: откройте настройки, перейдите на «Basics» и прокрутите вниз, за «Experimental settings». Полный порядок: Logs, NTP settings, Certificate Trust, Clash API, V2Ray API, Experimental settings, затем Advanced Collections.

В разделе три редактора, у каждого кнопка добавления:

- провайдеры сертификатов ACME, Tailscale и Cloudflare Origin CA;
- общие HTTP-клиенты;
- сетевые пространства имён Linux.

Раздел виден в обеих раскладках панели: в nexus-гриде и в классических expansion-панелях.

## 2. Что делают эти три коллекции

- Провайдеры сертификатов. Ядро получает сертификаты само, вручную их ставить не нужно. ACME выпускает и перевыпускает сертификаты Let's Encrypt через HTTP-01, TLS-ALPN-01 или DNS-01, поэтому inbound или endpoint с TLS получает настоящий сертификат без ручных шагов. Провайдер Tailscale берёт сертификаты у существующего Tailscale-эндпоинта. Cloudflare Origin CA выпускает сертификаты для серверов за Cloudflare.
- HTTP-клиенты. Именованный HTTP-транспорт, который настраивают один раз: движок, версии HTTP с первой по третью, заголовки, окна приёма, TLS и настройки исходящего соединения. ACME-провайдеры, rule-set и провайдеры ссылаются на такой клиент по тегу, а не повторяют настройки в каждом месте.
- Сетевые пространства имён (только Linux). Режим default открывает существующее пространство по пути; режим unshare создаёт изолированное при запуске ядра, и слушатели с исходящими соединениями работают внутри него. Сохранение формы меняет только конфигурацию, панель сама ничего не создаёт.

## 3. Что снова работает

- Добавление элемента открывает форму. Поля проверяются до сохранения: пустое обязательное поле выдаёт ошибку вместо тихого сбоя.
- Сохранённые элементы отображаются карточками с действиями «Edit» и «Delete». Удаление последнего элемента убирает пустую коллекцию из конфигурации.
- Кнопка Save панели записывает все три коллекции в базу одним запросом. Проверено на живой панели: в сохранённой конфигурации оказались ровно те элементы, что созданы в формах.

## 4. Новые поля протоколов из beta3 и где их искать

Beta3 добавил опции ядра существующим протоколам. Они живут в формах протоколов на страницах Inbounds и Outbounds, и большинство появляется после включения соответствующего переключателя:

- Hysteria, Hysteria 2 и TUIC: включите переключатель QUIC-настроек в форме протокола, и появятся таймаут простоя, период keep-alive, окна приёма потока и соединения, лимит одновременных потоков, начальный размер пакета и поиск MTU пути. У Hysteria 2 дополнительно есть BBR-профиль, realm со STUN-серверами, интервал смены порта и переключатель Chrome parrot.
- Mieru: MTU и режим рукопожатия в форме Mieru.
- MASQUE: локальный адрес и порт в форме MASQUE.
- WireGuard: UDP mapping, UDP filtering и лимиты UDP NAT в форме WireGuard.
- Эндпоинты OpenVPN (клиент и сервер), inbound cloudflared и службы usbip-server с usbip-client - отдельные записи на страницах Endpoints, Inbounds и Services.
